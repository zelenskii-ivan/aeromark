# Аэромарк

Учебный тренажёр для первоклассников: математика, русский язык, чтение и
игровой 3D-эпизод. Работает как PWA.

## Что внутри

| Каталог | Что там |
| --- | --- |
| `app/` | Next.js App Router: главный экран, урок, 3D-игра на three.js |
| `content/` | Задачи диагностики и миссий, генератор бесконечных примеров |
| `lib/` | Прогресс, синтез речи, клиент API и синхронизация |
| `server/` | Fastify + PostgreSQL: семьи, приглашения, серверный прогресс |
| `tests/` | Тесты логики: прогресс, содержание, генератор, речь |

Прогресс хранится на устройстве и работает без интернета. Если поднят
серверный слой из `server/`, во вкладке «Для взрослого» появляется вход в
семейный аккаунт: прогресс уезжает на сервер и открывается с других устройств.
Источник правды — устройство; при расхождении версий выбор делает родитель,
ничего не перезаписывается молча.

## Разработка

```bash
npm ci
npm run dev        # http://localhost:3000
npm test           # тесты логики
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
```

Сервер API:

```bash
cd server && npm ci && npm run dev
```

## Production на VPS

1. Скопируйте `.env.example` в `.env` и заполните — секреты генерируйте
   через `openssl rand -base64 32`.
2. Направьте A-запись домена на IP сервера.
3. `docker compose up -d --build`.
4. Проверьте `https://ваш-домен/health`.
5. Создайте семейное приглашение через `POST /api/admin/invites`.

Подробности — в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md), про безопасность —
в [docs/SECURITY.md](docs/SECURITY.md).

Рекомендуемый сервер: Ubuntu 24.04 LTS, 2–4 vCPU, 4–8 ГБ RAM, 80 ГБ NVMe и
ежедневные резервные копии базы.

Никогда не коммитьте `.env`, пароли, токены и ключи API.
