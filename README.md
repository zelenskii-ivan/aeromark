# Аэромарк

Учебный тренажёр для первоклассников: математика, русский язык, чтение и игровые 3D-эпизоды.

## Текущий режим

Публичный пилот работает как PWA и хранит прогресс локально. Production-слой в `server/` добавляет семейные аккаунты, детские профили, PIN, серверный прогресс и управляемые приглашения.

## Запуск интерфейса

```bash
npm ci
npm run dev
```

## Production на VPS

1. Создать закрытый файл `.env` по перечню переменных из `docs/DEPLOYMENT.md`.
2. Указать домен в `DOMAIN` и `APP_ORIGIN`, сгенерировать уникальные секреты.
3. Направить DNS-запись домена на IP сервера.
4. Запустить `docker compose up -d --build`.
5. Создавать семейные приглашения через защищённый административный API.

Рекомендуемый сервер: Ubuntu 24.04 LTS, 4 vCPU, 8 ГБ RAM, 80–100 ГБ NVMe и ежедневные резервные копии.

Никогда не коммитьте `.env`, пароли, токены и ключи API.
