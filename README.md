# Аэромарк

Учебный тренажёр для первоклассников: математика, русский язык, чтение и
игровой 3D-эпизод. Работает как PWA.

## Что внутри

| Каталог | Что там |
| --- | --- |
| `app/` | Next.js App Router: главный экран, урок, 3D-игра на three.js |
| `app/su57/`, `lib/su57/`, `public/models/` | Игровой эпизод 02: ребёнок и 3D-Марк по очереди собирают Су-57 в ангаре |
| `content/` | Уроки, задачи диагностики и миссий, генератор примеров |
| `app/academy/`, `lib/academy/`, `content/academy/` | Академия пилотов — раздел чтения, см. [docs/READING_ACADEMY.md](docs/READING_ACADEMY.md) |
| `docs/METHODOLOGY.md` | Чему и в каком порядке учит приложение и почему |
| `lib/` | Прогресс, синтез речи, клиент API и синхронизация |
| `server/` | Fastify + PostgreSQL: семейные кабинеты, подтверждение почты, серверный прогресс |
| `tests/` | Тесты логики: прогресс, содержание, генератор, речь |

Приложение не проверяет знания, а учит: каждый урок ведёт ребёнка через
одиннадцать фаз — от задачи, которую нечем решить, к открытию руками, схеме и
только затем к правилу. Методическая основа и её источники — в
[docs/METHODOLOGY.md](docs/METHODOLOGY.md).

Прогресс хранится на устройстве и работает без интернета. Если поднят
серверный слой из `server/`, во вкладке «Для взрослого» появляется вход в
семейный аккаунт: прогресс уезжает на сервер и открывается с других устройств.
Источник правды — устройство; при расхождении версий выбор делает родитель,
ничего не перезаписывается молча.

## Разработка

```bash
npm ci
npm run dev        # http://localhost:3000
npm test           # тесты логики
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
```

Сервер API:

```bash
cd server && npm ci && npm run dev
```

## Production на VPS

Сайт аэромарк.рф работает на VPS: системный nginx с сертификатом certbot
принимает HTTPS и передаёт запросы в контейнеры `web` и `api` из
[prod/compose.yml](prod/compose.yml). Выкладка — скриптом, сначала на
staging, потом на прод:

```bash
/opt/aeromark/src/prod/deploy.sh staging
/opt/aeromark/src/prod/deploy.sh prod
/opt/aeromark/src/prod/deploy.sh prod --rollback   # вернуть прошлый релиз
```

Всё про сервер, резервные копии и staging — в [prod/README.md](prod/README.md),
про письма и данные — в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md), про
безопасность — в [docs/SECURITY.md](docs/SECURITY.md).

Рекомендуемый сервер: Ubuntu 24.04 LTS, 2–4 vCPU, 4–8 ГБ RAM, 80 ГБ NVMe и
ежедневные резервные копии базы.

Никогда не коммитьте `.env`, пароли, токены и ключи API.
