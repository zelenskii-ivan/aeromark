# Безопасность

Текущая серверная основа включает Argon2 для паролей и PIN, хешированные сессионные токены, HttpOnly/Secure cookie, одноразовые приглашения, ограничение частоты запросов, проверку входных данных, изоляцию семей и блокировку доступа владельцем.

Перед публичным запуском обязательны:

- отдельный deploy-пользователь и вход на VPS только по SSH-ключу;
- закрытые порты PostgreSQL и API, наружу доступны только 80/443;
- Cloudflare Proxy, WAF, rate limiting и защита от DDoS;
- ежедневные зашифрованные резервные копии с тестом восстановления;
- уникальные production-секреты вне Git;
- мониторинг доступности и ошибок;
- политика конфиденциальности и согласие родителя, поскольку сервис предназначен для детей;
- минимизация собираемых данных: не хранить фамилию, адрес, школу, голос или переписку ребёнка без отдельной необходимости и согласия.

Ни один интернет-сервис нельзя гарантированно защитить «от любого взлома». Цель — многослойная защита, быстрое обнаружение инцидента и восстановление без потери данных.
