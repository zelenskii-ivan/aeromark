# Безопасные дороги — подготовка для 1 класса

Отдельный раздел на главном экране AeroMark. 15 авторских заданий, пять тем на трёх уровнях: переходы, пешеходный светофор, знаки, безопасный маршрут, дорожные ловушки. Не является официальным тренажёром Учи.ру и не содержит официальных заданий. Нет таймера, лимитов занятий или платных ограничений. Уровни открыты сразу; пять вопросов в обычной тренировке, случайный порядок ситуаций.

## Архитектура

- `content/roads/tasks.ts`: вопросы, ответы, объяснения, проверка выбора и последовательностей.
- `lib/roads/state.ts`: валидируемое состояние, тренировки, ошибки, однократные звёзды.
- `app/roads/`: отдельный клиентский экран, схемы на SVG и стили в палитре AeroMark; общий Button и Progress.
- `Saved.roads` в `lib/progress.ts`: миграция старых сохранений, локальное хранение, импорт/экспорт и существующая синхронизация по childId. Изменение схемы PostgreSQL не требуется: сервер хранит payload JSON. Конфликты версий остаются в существующем интерфейсе родителя.

Каждый ответ записывается сразу. Сохраняются очередь, позиция и проверенный ответ: перезагрузка не позволяет повторно засчитать его. Кнопка «К карте» оставляет тренировку для продолжения; запуск другого уровня заменяет незавершённую очередь, но сохраняет все ответы и награды. Ошибочный ответ добавляет задачу в повторение, верный убирает. Звезда за задачу выдаётся один раз, значок темы — за три освоенные ситуации. Прогресс ограничен размером банка заданий, число тренировок не ограничено.

Озвучка использует существующий `lib/speech.ts`: ru-RU, обычный и замедленный темп, чтение вопросов, вариантов и объяснений. Если русский системный голос недоступен, показано сообщение; аудиофайлы не поставляются. При смене вопроса/экрана речь останавливается. Для визуальных сцен есть текстовые описания, кнопки доступны с клавиатуры, выбранные варианты имеют aria-pressed.

## Проверка

`npm test`, `npm run typecheck`, `npm run lint`, `npm run build`.
В `tests/roads.test.mjs` проверяются полнота тем, валидность ответов, последовательности, повторение ошибок, однократные награды, неограниченные повторы, восстановление сессии через JSON/экспорт, повреждённые данные и устаревшие ответы.

Для ручной проверки: открыть раздел из кабинета, пройти уровень, намеренно ошибиться, вернуться к карте, повторить ошибку, перезагрузить страницу посреди тренировки и продолжить. Проверить русский голос на целевом устройстве Марка. Проверка реальной межустройственной синхронизации требует тестового семейного сервера; не используйте продакшен для тестовых ответов.

Проверено при реализации: 97 тестов, TypeScript и ESLint проходят; production-сборка с `--webpack` проходит. Стандартный Turbopack в локальной среде завершился ошибкой разрешений при открытии порта для обработки CSS. В браузере с временным локальным API проверены вход из кабинета, неверный ответ, восстановление после перезагрузки, повторение ошибки и выдача звезды. Тестовые API удалены из итогового изменения. Реальная база и межустройственная синхронизация не проверялись.
