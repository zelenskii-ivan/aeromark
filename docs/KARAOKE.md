# Чтение-караоке

Открывается: главная → Академия пилотов → Чтение-караоке. Аналитика: «Для взрослого», после существующего PIN.

## Сценарий

1. Выберите простой рассказ. Объясните незнакомые слова, прочитайте трудное слово вместе.
2. Начните в своём темпе: статичный текст, кнопка следующего слова. При необходимости включите караоке по слогам или словам, 5–90 слов/мин. Бегущая строка включается отдельно.
3. Остановитесь при усталости. Таймер можно скрыть; паузы и время в другой вкладке исключаются. По окончании подсветки таймер останавливается; если ребёнок продолжает читать, нажмите «Продолжить».
4. Нажмите «Завершить». Ответьте на вопросы, найдите подтверждение в тексте, попросите короткий пересказ.
5. Взрослый подтверждает прослушанное чтение, указывает последнее прочитанное слово и отмечает ошибки. Без подтверждения сохраняется практика без скорости.
6. Повторите по желанию; затем проверьте чтение нового текста без подсветки.

## Расчёты и ограничения

Слова вычисляются регулярным выражением Unicode из исходного текста без слоговых разделителей. Пунктуация не считается, внутренний дефис сохраняет одно слово, числа считаются токенами. Заглавие исключено. Это явно заданная политика приложения, а не утверждённая ФРП методика токенизации.

Слова/мин = подтверждённые слова × 60000 / активные миллисекунды; верные слова/мин = (слова − уникальные слова с ошибкой) × 60000 / активные миллисекунды. Округление только для показа, до одного десятичного знака. Пропуск считается ошибкой, самостоятельное исправление — нет. Повторное ошибочное произнесение того же слова не добавляет вторую ошибку. Частично прочитанное последнее слово исключается. Замер с остановками — показатель практики, не стандартизированный школьный тест.

Подсветка не слушает ребёнка. Настроенный темп не записывается как фактическая скорость. Слоговые части размечены вручную; исходный текст сохраняет пунктуацию. На слово отводится 60/темп секунд, распределённых между его слогами. Это удобная проектная модель, не фонетическая длительность речи. Таймер использует performance.now; смена темпа применяется после учёта прошедшего отрезка. При разрыве между тиками более 2 секунд занятие ставится на паузу без зачёта разрыва.

Адаптация предлагает уменьшить темп на 3 при точности ниже 90% или неверном ответе. Два полных подтверждённых повтора с точностью ≥95% и верными отвеченными вопросами предлагают +2. Это эвристики продукта, не научные нормы. Короткие попытки <5 секунд исключены из адаптации. Совет применяется кнопкой взрослого. Пропущенные вопросы не считаются неверными; ответы показаны с собственным знаменателем.

История — academy.karaoke, последние 60 записей, в существующем семейном сохранении, экспорте и синхронизации. Повторная запись с тем же id игнорируется. Схема отбрасывает повреждённые записи отдельно; старые сохранения получают пустой журнал. Первое/повторное чтение определяется внутри сохранившейся истории, не за всю жизнь ребёнка. Незаконченное занятие не восстанавливается после перезагрузки. Нынешняя версия не записывает аудио, подсказки взрослого и изменения темпа внутри занятия; pace хранит конечную настройку.

## Проверка

`npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.

Тесты karaoke.test.mjs покрывают Unicode-токены, 37 слов оригинального рассказа, восстановление текста из слогов, время и изменение темпа, WPM/WCPM, подтверждение взрослого, ошибки, ограничение журнала, повторную отправку, миграцию и условия адаптации. Исследование и правовые основания: KARAOKE_RESEARCH.md.

## Новые рассказы

В библиотеке 30 разных текстов: один рассказ Ушинского и 29 авторских учебных упражнений с двумя вопросами к каждому. Авторские упражнения не обозначаются произведениями из перечня ФРП. При открытии автоматически выбирается ещё не встречавшийся текст, затем — тот, который читали давнее всего. После сохранения кнопка «Новый рассказ» сразу открывает следующий. «Повторить рассказ» оставлено для осознанной практики. Подбор использует общий журнал из 60 занятий и переносится вместе с ним между устройствами. Удаление истории сбрасывает сведения о знакомстве с текстами.
