# Развёртывание Аэромарка

## Требования

- Ubuntu 24.04 LTS
- 4 vCPU, 8 ГБ RAM, 80–100 ГБ NVMe
- Docker Engine и Docker Compose
- домен с A-записью на IP сервера

## Первый запуск

1. Клонируйте репозиторий на сервер.
2. Создайте закрытый `.env` с переменными `DOMAIN`, `APP_ORIGIN`, `DATABASE_URL`, `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` и `ADMIN_BOOTSTRAP_TOKEN`.
3. Сгенерируйте пароль базы и административный токен командами `openssl rand -base64 32`. Не публикуйте полученные значения.
4. Укажите домен в `DOMAIN`, а полный HTTPS-адрес сайта в `APP_ORIGIN`.
5. Выполните `docker compose up -d --build`.
6. Проверьте `https://ваш-домен/health`.

Caddy автоматически выпустит и обновит TLS-сертификат. PostgreSQL хранится в отдельном Docker volume. До выдачи приглашений настройте ежедневную зашифрованную резервную копию базы вне сервера.

## Приглашения

Код создаётся владельцем через `POST /api/admin/invites` с заголовком `x-admin-token`. Код одноразовый: после регистрации семьи повторно использовать его нельзя. Семью можно заблокировать через административный endpoint; все её активные сессии будут удалены.

## Обновление

```bash
git pull --ff-only
docker compose up -d --build
docker compose ps
```

Обновление базы выполняется приложением при старте. Перед обновлением production сначала сделайте резервную копию PostgreSQL.
