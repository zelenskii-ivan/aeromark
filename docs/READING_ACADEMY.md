# Академия пилотов — раздел чтения

Раздел для первоклассника, который читает по буквам и слогам (стартовая точка
Марка — 8 слов в минуту 30.09.2026). Цель — точность, слияние, скорость и
понимание, без давления и без наказания за ошибки.

## Программа

1. **Буквы** — услышать и найти букву, найти картинку на эту букву.
2. **Звуки** — первый звук слова, одинаковые/разные слоги, есть ли буква в слове.
3. **Слоги** — сцепка согласной с гласной, прочитать слог и выбрать, как он
   звучит (три кнопки-динамика — это проверка чтения, а не слуха), найти
   услышанный слог; в конце — обратные слоги (АМ, ОН).
4. **Слова** — прочитать слово и найти картинку (отвлекающие слова похожи
   написанием: дом / дым / рот), собрать слово из слогов.
5. **Предложения** — картинка к предложению, «так бывает?», пропущенное слово
   с нужным окончанием.
6. **Рассказы** — прочитать, ответить и показать, где это написано
   («что + откуда»). Засчитывается только пара: ответ без улики может быть
   угадан.

Картинка никогда не заменяет чтение: в заданиях на чтение слово не
озвучивается, пока ребёнок не попросил подсказку.

Уроки открываются по порядку; пройденный урок можно повторять; «Свободный
полёт» доступен всегда и не ограничен.

## Модель усвоения

У каждой единицы (буква, слог, слово, вопрос) — «коробка» 0–5:

- верно без подсказки → +1;
- верно с подсказкой → без изменений;
- ошибка → −2 (не ниже 0).

Коробка 3+ — «усвоено». Повтор через 0, 1, 2, 4, 7, 14 дней по коробке.
«Нужна практика» — от трёх попыток и точность ниже 70% или коробка ≤ 1.

Полёт: около ⅔ — материал урока, ⅓ — повторение того, что пора повторить, и
трудного. Одна единица — не больше двух раз за полёт и не подряд.

Трудность: 2–4 варианта ответа. Две ошибки подряд — вариантов меньше; уверенный
навык — больше и отвлекающие варианты похожее (Б/Д, Ш/Щ).

Урок пройден при 70% верных с первой попытки. Если нет — «ещё один полёт»,
ничего не отнимается.

## Награды

- звезда — за верный ответ с первой попытки, дневной потолок 60;
- монеты — за впервые пройденный урок (10), аэропорт (30), достижение (5);
- самолёты — за пройденные аэропорты и за монеты;
- каждая разовая награда записывается в журнал и второй раз не выдаётся;
  повторная отправка того же полёта игнорируется.

## Озвучка

Решение: **готовые записи** голосом macOS «Милена»; запасной путь —
синтезатор браузера.

Первая версия была на RHVoice «Dasha» (CC BY-SA 4.0): по отзыву —
роботизированно, растянуто, слоги непонятные. Нейросетевые голоса (Piper,
Silero) и облачные (Яндекс SpeechKit) из среды разработки недоступны, поэтому
записи сделаны на Mac разработчика системным голосом — он естественнее.

Почему не синтез в браузере (было): голос разный на каждом устройстве, на части
Android и Linux русского нет, отдельный слог читается как аббревиатура.

Согласный звук отдельно синтезатор надёжно не произносит, а по методике
буква озвучивается только звуком, никогда названием («эм»). Поэтому для
согласной звучит опорное слово («мост» → М), для гласной — сам звук.

Каждая запись проверяется: не тишина, длительность в пределах для своей
длины (защита от «чтения по буквам»: все слоги 0,4–0,7 с). Скорость по
умолчанию обычная, «улитка» — 0,85, без изменения высоты голоса.

Перезапись (на Mac):

```bash
node --experimental-strip-types scripts/academy-audio/collect.mjs > /tmp/list.json
# список → aeromark-phrases.tsv (номер, категория, текст), затем на Mac:
bash ~/Downloads/aeromark-voice.sh        # → ~/Downloads/aeromark-voice.zip
python3 scripts/academy-audio/import.py /tmp/list.json <распакованный архив>
```

Лучшее качество — голос «Milena (улучшенный)»: Настройки → Универсальный
доступ → Устный контент → Системный голос → Управлять голосами.

## Лётный тест

Добровольный. «Тренировка» — без часов. «Лётный тест» — секундомер, взрослый
отмечает слова с ошибкой и слово, где остановились; затем вопросы на
понимание. Главная цифра — верные слова в минуту. Рекорд засчитывается,
только если точность не упала.

## Хранение и безопасность

Состояние — поле `academy` в общем сохранении: синхронизируется с семейным
сервером без изменения API и миграций, изоляция семей — та же. Незаконченный
полёт хранится на устройстве и продолжается после перезагрузки. Секретов в
клиенте нет.

## Известные ограничения

- Записи сделаны синтезатором macOS и проверены автоматически; ударения стоит
  прослушать взрослому.
- Тренажёр не слышит чтение вслух: в лётном тесте ошибки отмечает взрослый.
- Картинки — эмодзи; на старых устройствах некоторые могут выглядеть иначе.
